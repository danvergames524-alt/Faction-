# FACTION — Minecraft Clan

Статический адаптивный сайт на HTML, CSS и JavaScript. Он не требует сервера, установки программ или сборки и подходит для GitHub Pages. Изображение главного экрана уже включено в `assets/faction-minecraft.png` — это изображение, предоставленное для проекта.

## Быстрый запуск

1. Скачайте ZIP-архив и распакуйте его.
2. Откройте папку `Faction_Minecraft_Site`.
3. Убедитесь, что `index.html`, `style.css`, `script.js` и `README.md` лежат в корне этой папки, а изображение — в `assets/faction-minecraft.png`.
4. Для локального просмотра просто откройте `index.html` в браузере. Никакие дополнительные программы не нужны.

## Как изменить персонал

1. Откройте `script.js` в любом текстовом редакторе.
2. В начале файла найдите массив `staffMembers`.
3. Изменяйте `name` (никнейм), `role` (должность) и `description` (обязанности).
4. Чтобы добавить участника, скопируйте один объект в массив и поменяйте значения. Чтобы удалить — удалите соответствующий объект.
5. Сохраните файл. Все карточки персонала генерируются автоматически из этого массива.

Данные в массиве сейчас демонстрационные. Замените их актуальными никами перед публикацией.

## Как изменить новости

В `script.js` найдите массив `newsItems`. Для каждой публикации можно изменить:
- `date` — дата или подпись даты;
- `category` — категория;
- `title` — заголовок;
- `description` — описание;
- `icon` — декоративный символ.

Это статический сайт: форма публикации не предусмотрена, а GitHub Pages не хранит отправленные пользователями данные. Чтобы опубликовать изменения, отредактируйте массив и загрузите обновлённый `script.js` в репозиторий.

## Как поменять цвета и фон

- Цвета находятся в начале `style.css` в блоке `:root` — измените CSS-переменные.
- Основное изображение хранится локально по адресу `assets/faction-minecraft.png`. Замените этот файл своим изображением, сохранив то же имя, или измените относительный путь в `style.css` и `index.html`.
- Все ссылки на локальные ресурсы относительные, поэтому сайт совместим с адресами вида `username.github.io/repository-name/`.

## Страница «Сообщество»

В верхнем меню появилась вкладка **«Сообщество»** с карточками Telegram и Discord. Раздел открывается без перезагрузки по адресу `#community`.

Чтобы изменить ссылки, откройте `index.html`, найдите блок `id="page-community"` и поменяйте адреса в атрибутах `href` у кнопок «Открыть Telegram» и «Открыть Discord». Для внешних ссылок сохраните `target="_blank"` и `rel="noopener noreferrer"`.

## Косметика профиля и демо-магазин

В окне профиля доступна «Мастерская профиля» с восемью категориями и 64 косметическими предметами: аватары, рамки, фоны, эффекты, стили ника, титулы, значки и темы карточки. В каталоге работают поиск, фильтр редкости и избранное. Предметы можно примерять до покупки; после покупки баланс и инвентарь сохраняются сразу. Кнопка «Применить оформление» применяет только принадлежащие игроку предметы.

В мастерской есть загрузка собственного аватара (PNG/JPG/WebP до 5 МБ; изображение уменьшается до 256×256), три слота образов и анимированный предпросмотр. Образы можно сохранять и загружать для примерки. Косметика действует только на сайте и не влияет на Minecraft.

**Важно:** магазин является фронтенд-демонстрацией. Баланс FacCoins начинается с 1 250 FC и хранится локально, не связан с реальными платежами, Minecraft-сервером или FactionBot. Данные можно изменить в инструментах разработчика браузера, поэтому такая реализация не подходит для настоящей экономики без серверной проверки. Изображение аватара, избранное, инвентарь и образы сохраняются в `localStorage` этого браузера.

Каталог и цены находятся в `script.js` в объекте `cosmeticCatalog`; начальный баланс и бесплатные предметы — в `cosmeticDefaults`. Оформление мастерской находится в конце `style.css` в разделе `FACTION COSMETIC WORKSHOP`.

## Публикация на GitHub Pages

1. Войдите на [GitHub](https://github.com/) и создайте новый репозиторий. Например, `faction-minecraft-site`.
2. Распакуйте ZIP на компьютере.
3. Откройте папку `Faction_Minecraft_Site`. Загрузите **содержимое** этой папки в корень репозитория: `index.html`, `style.css`, `script.js`, `README.md` и папку `assets`. Не загружайте ZIP вместо файлов и не помещайте всё содержимое в лишнюю вложенную папку.
4. На странице репозитория откройте **Settings → Pages**.
5. В разделе **Build and deployment** в поле **Source** выберите **Deploy from a branch**.
6. В поле **Branch** выберите `main`, а в каталоге — `/(root)`.
7. Нажмите **Save**.
8. Подождите, пока GitHub Pages опубликует сайт. Адрес появится в разделе **Settings → Pages** и обычно имеет вид `https://ВАШ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
9. Чтобы обновить сайт, измените нужные файлы и загрузите их в тот же репозиторий с коммитом. GitHub Pages автоматически опубликует обновление после завершения развёртывания.

Если у репозитория другое имя или сайт публикуется из другой ветки, адрес и настройки могут отличаться.

## Примечания

- Вкладки работают без перезагрузки и поддерживают прямые ссылки `#home`, `#staff`, `#news` и историю браузера.
- Мобильная навигация, адаптивная сетка и анимации встроены.
- Учитывается настройка `prefers-reduced-motion`.
- Реальные показатели онлайна, участников и достижений не добавлены.
- Ники персонала и новости — примеры, их нужно заменить перед официальной публикацией.


## Профиль игрока

В шапке сайта доступен кастомный профиль. Никнейм сохраняется локально в браузере. Баланс FacCoins и остальные показатели демонстрационные и не синхронизируются с ботом. После подключения backend/бота их можно заменить реальными данными.

Для приветственного экрана используется отдельный файл `assets/faction-welcome.jpg`; основной фон сайта остаётся в `assets/faction-minecraft.png`.
