# Faction Clan Site (HTML + CSS + JavaScript)

Статический сайт без React, Vite, npm и сборки. Подходит для GitHub Pages.

## Файлы
- `index.html` — структура страницы и тексты
- `style.css` — дизайн, цвета, адаптивность
- `script.js` — интерактивность, состав и новости

## Публикация на GitHub Pages
1. Распакуй архив.
2. Открой репозиторий GitHub своего сайта.
3. Нажми **Add file → Upload files**.
4. Перетащи **содержимое папки** проекта: `index.html`, `style.css`, `script.js`, `README.md` (не саму внешнюю папку).
5. Нажми **Commit changes**.
6. Открой **Settings → Pages**. В разделе Build and deployment выбери **Deploy from a branch**, branch `main`, folder `/ (root)`, затем Save.
7. Подожди завершения публикации и обнови страницу сайта через Ctrl+F5.

## Редактирование персонала
На сайте нажми «Редактировать состав». Можно добавить, изменить и удалить карточки. Изменения сохраняются в localStorage только в твоём браузере. Для резервной копии нажми «Экспорт данных JSON».

Важно: браузерное редактирование не изменяет файлы на GitHub и не делает изменения видимыми другим посетителям. Чтобы опубликовать изменения всем, отредактируй `script.js` в репозитории или внеси правки локально и загрузи файл заново.
