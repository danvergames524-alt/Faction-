# FACTION Minecraft Clan Website

Статический сайт на обычных HTML, CSS и JavaScript. React, npm и сборка не нужны.

## Файлы
- `index.html` — структура сайта
- `style.css` — дизайн и адаптивная вёрстка
- `script.js` — интерактивность и редактор состава

## Публикация на GitHub Pages
1. Загрузите эти три файла в корень репозитория.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/(root)`, затем нажмите **Save**.

## Редактор персонала
Изменения сохраняются в `localStorage` браузера и видны только в этом браузере. Кнопки экспорта и импорта позволяют переносить данные JSON вручную. Чтобы опубликовать обновлённый состав для всех посетителей, нужен общий backend или изменение исходных файлов и повторная публикация.

## Настройка
Тексты и статические новости редактируются в `index.html`. Цвета находятся в начале `style.css` в блоке `:root`.
